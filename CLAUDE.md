# Project notes

Single-page itinerary app. Everything lives in `index.html`: the styles, the
`DAYS` data, and the Leaflet map logic, with no build step. Open the file in a
browser, or serve the folder, to see changes.

## Commit and PR conventions

Do not add attribution trailers to commit messages or pull request
descriptions. Specifically, leave out `Co-Authored-By: Claude ...`,
`Claude-Session: ...`, and the "Generated with Claude Code" footer.
